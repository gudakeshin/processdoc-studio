# Complete Run

## Purpose

The Complete Run process ensures that all project activities, quality assurance checks, and governance controls are executed to their conclusion. This process is essential for delivering validated outputs that meet organizational standards and compliance requirements. By establishing a clear completion protocol, the organization maintains consistency in project delivery and ensures that all remediation actions are properly documented and resolved before final sign-off.

## Scope

This process covers the execution of the final run activities, including quality assurance validation and guardrail compliance verification. The scope encompasses all systems and tools required to execute the run, document outcomes, and apply necessary remediation when initial quality checks fail. The process concludes when all quality and governance requirements have been satisfied and documented.

## Roles and Responsibilities

- **Process Owner**: Responsible for executing the complete run, managing quality assurance outcomes, applying remediation actions when QA checks fail, and ensuring all guardrail compliance requirements are met before process completion.

## Procedure

1. Execute the complete run according to project specifications and established protocols. Ensure all required inputs are available and all systems are properly configured before initiating the run.

2. Monitor quality assurance (QA) outcomes throughout the run execution. Document all QA results and identify any areas where the QA validation fails to meet established standards.

3. When QA outcomes fail, immediately apply the designated remediation actions to address identified deficiencies. Document all remediation steps taken and the rationale for each corrective action.

4. Verify guardrail compliance requirements are satisfied. If guardrail validation fails, escalate the issue and determine appropriate corrective measures before proceeding.

5. Confirm that all remediation actions have been completed and that both QA and guardrail outcomes now satisfy organizational requirements.

6. Document the final completion status, including all remediation actions applied, outcomes achieved, and any residual issues or recommendations for future runs.
