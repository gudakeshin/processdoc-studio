# Build a Narrative — Executive Briefing

## What This Process Does

This process enables the creation of structured, evidence-grounded narratives that communicate key business insights and strategic direction to senior stakeholders. The Process Owner initiates narrative development by synthesizing available data, context, and evidence into a cohesive written summary. The output serves executives, boards, and decision-makers who require concise, actionable briefings.

## Key Activities

- **Synthesize evidence and context into narrative structure** — Process Owner
- **Validate claims against available data sources** — Process Owner
- **Produce concise, stakeholder-focused briefing** — Process Owner

## Roles and Accountability

- **Process Owner**: Responsible for gathering evidence, structuring narrative, and delivering executive-ready output within agreed timelines.

## Recommended Next Actions

1. Define narrative scope and target audience before initiating synthesis work.
2. Establish evidence validation criteria and data source requirements upfront.
3. Create a narrative template aligned with organizational communication standards.
4. Schedule stakeholder review gate before final briefing distribution.
